# Strata Worker — limited supervised preview

A local implementation subagent with host-owned scoped edits, checks, finite repair and canonical evidence. Primary still plans and independently accepts. Not general autonomous coding.

One fresh isolated project copy per unit. Fixed create-only run material is not a reusable task queue; do not clear history or reset budgets to rerun. Primary reviews any diff before transferring it.

Install into a trusted project without an existing `.local-agents`: `python -B install.py --target C:/work/my-project`. See [usage and safety](docs/strata-preview.md) and [configuration](examples/strata-preview/config.example.json).

Requires an existing Strata harness0.2.1-alpha.3, Node, iq3_s model and project checks. No LM Studio service/lms, bundled model, upstream SDK defaults, shell/Web/skills or recursive agent. Shared safety-kernel legacy modules are inert dependencies, not enabled roles.

Six independently accepted runs cover three exposed single-function contracts, not holdout or universal capability. Semantic repair passed offline, not exercised by first-pass live successes. Cloud savings unknown.
