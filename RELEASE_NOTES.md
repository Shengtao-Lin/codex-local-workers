# Strata Worker 0.1.0 Preview 1

A limited supervised implementation subagent using the local Strata native
Agent loop and the kit's shared, trusted safety kernel. This is a prerelease,
not a general autonomous coding release or a replacement for Primary review.

## Included

- Native local-only Strata route; no LM Studio service or lms command required.
- Approved-manifest reads/searches, one-function edits, host formatting/checks,
  finite repair feedback, version binding and immutable execution evidence.
- Create-only installation and a verified configuration example.
- A frozen distribution without models, upstream harness binaries, machine
  configuration or experiment request histories.

## Evidence and limits

Three already-exposed task families were repeated twice: strict UTF-8 parsing,
chronological tool-event aggregation and transient-key request hashing. All six
passed complete independent project tests, static checks and Primary diff review.
The respective project test counts were164/158/165 per run. This is not unseen
repository transfer or proof of general coding capability; prior failed batches
remain failures and are not overwritten by these results.

Offline real-host failed-draft/repair and four native fault controls passed.
The six live runs passed their first effective edit, so autonomous semantic
repair in live tasks remains unproven. No cloud-usage savings were measured.

Each task requires a fresh isolated project copy, an explicit contract/protected
tests and full Primary final acceptance. Reusing the same workspace for another
unit, resetting history/budgets, multi-file edits, test authoring, automatic
resume, fresh Local Reviewer, Explorer/Coordinator and Web/skills are not enabled.
Validation executes trusted project code with the host's permissions; this is
not operating-system isolation.

Requires existing Strata harness0.2.1-alpha.3, Node, the recorded iq3_s model
resident alone with parallel1/context>=65536, and the project's Python checks.
See docs/strata-preview.md for installation, permissions and acceptance duties.
