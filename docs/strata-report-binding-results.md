## 这次证明什么

在相同合同、源码、模型与总预算下，这批已暴露任务可以经有界恢复完成，
不会再因模型少复制一个编号或换行而丢掉正确来源。文档任务用完两次长度修复后
仍成功交付，体现有效恢复，而不是要求一次做对。

前批相同三题为交付2/3、事实接受1/3、18请求/1247.124秒；它不被本次覆盖。
引用协议、上下文/schema与汇总反馈构成组合变化，不能把全部收益归于单一因素。
多类机械错误同稿汇总在离线实测；本次live的无效报告只出现长度问题，不能声称
live已经单独证明了“多错汇总”的收益。先前语义分支错误本次未出现，也不能据此
断言该类语义错误已经普遍解决。

三题均已暴露，原生context为fresh且未传入旧Primary结论/成功答案，但并非新holdout。
没有统计稳定成功率、新仓库迁移或长期经济收益证明。Reviewer/Coder/Coordinator未
参与本次只读批次；不能用此成绩更新它们的live资格。实现与独立审查路线未变。

## 受限使用

仅用于可信本地项目、明确材料范围的普通`investigate`。合并进已有有效Strata配置：

```json
{
  "experimental_strata_task": true,
  "experimental_strata_report_receipt": true,
  "experimental_strata_report_binding": "observed-line-v1"
}
```

这是配置片段，不替代模型/tokenizer/Python等本机配置。该组合拒绝implement与能力
工具配置，不能自动联网、执行脚本或派孩子。旧quote协议默认不变。试验产品冻结于
本批次`candidate/product/`，尚未发布新默认版本或推送远端。

Primary仍审批目标/范围并独立核对完整正文、未知项与证据；机械短预览不是摘要或验收。
下一步若要扩大资格，应换未见任务验证迁移，不继续拿同三题反复堆通过数。
