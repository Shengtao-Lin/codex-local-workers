# v2.1 execution implementation

Primary feature id: `v2-1-supervised-execution`. Feature and integration risk:
high (archive authority, process boundaries, dependency progression).

The candidate6 gate permits localization-only, Primary-supervised operation.
It is not qualification of a generative Coordinator model or unattended
semantic investigation. Existing dirty changes and historical archives remain
unchanged; no Git publication is part of this implementation.

## Units and gates

| Unit | Risk | Dependencies | Owned contract | Acceptance |
| --- | --- | --- | --- | --- |
| Compact archive handoff | high | existing archive validators | `handoff-not-acceptance` | Explicit accepted run references, independent integration freshness, no state writes, missing evidence never success, invalid evidence rejected. |
| Coordinator role probe | high | existing packet/decision validators | `model-output-not-authority` | Independent Muse context, one bounded correction, Primary identity/risk/scope clamp, immutable evidence, no dispatch or acceptance from syntax pass. |
| Supervised execution manager | high | compact handoff | `dispatch-authority` | Primary-authorized capability and proposals, serialized dispatch, dependency acceptance gates, no automatic retry of uncertain process loss. |
| Bounded recovery | high | manager | `recovery-authority` | Preserve existing explicit authorization, narrow scope and unique run identity; ambiguous/semantic failures escalate. |
| Integration and efficiency evidence | high | all above | `feature-final-review` | Fresh multi-unit route, actual cumulative diff review, passing regression and recorded limitations; no inferred savings from token counts. |

Implementation proceeds with frozen critical tests, current role IDs and serial
model loading. A local Coordinator model is not silently selected or qualified.
The deterministic supervised path can ship independently; model-authored
generative routing and its role-compatibility/semantic evaluation remain
separate gates. Neither this document nor a compact summary accepts a feature.

Stop when the approved v2.1 implementation gates pass, or weekly used reaches
20% (80% remaining), using the account usage tool rather than a token estimate.
