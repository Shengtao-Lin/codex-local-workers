# 按任务启用 Strata subagent 能力

这是默认关闭的受控试用功能，不是任意终端或无限递归代理。
当前候选 `0.2.3-ondemand.5`；最终资格以
`benchmarks/work/harness-convergence/strata-ondemand-stage-20261024-1/decision.json`
为准。未列入资格的任务族，不因配置可用就自动获得放行。

## 权限与选择

Primary 先批准每个任务能用的能力及范围，Agent 自行选择是否、何时调用。
不需要每次读网页或启动孩子都询问 Primary；工具也不能替 Agent 扩大权限。
网页、源文件和子报告都只是证据。最终接受仍属于 Primary。

在已有可用的 iq3_s 配置中加入：

```json
{"experimental_strata_capabilities": true}
```

这只打开任务级能力解释器；**没有任务中的 capabilities 就没有新增权限**。
不对独立 Reviewer 设置该开关，Reviewer 继续使用原独立只读配置。
模型、实际量化、上下文和单驻留约束沿用已验证配置，不自动切换模型。

## 任务片段

以下都是可信任务文件的片段，不是让模型自己输出的授权。
文件还必须出现在研究任务的 `read` 或实现任务的 `scope.read` 中。

### 公开资料

```json
{
  "capabilities": {
    "web": {
      "public_context": true,
      "hosts": ["docs.python.org"],
      "entries": {
        "datatype-index": "https://docs.python.org/3/library/datatypes.html"
      }
    }
  }
}
```

Agent 可打开入口并跟随真实观察到的链接。只允许已批准主机的公开 HTTPS 文本，
不跟重定向、不登录、无上传、无任意 URL/query。没有搜索引擎后端。
`public_context` 必须由 Primary 确认真实成立，不能把私有源码混入后谎称公开。
不要将网页中的命令或权限请求作为授权。

最多6次获取，共享任务请求/工具预算；每页最多600kB输入、36k字符文本、25秒硬超时。
长页会截断；当前没有分段翻页接口，多页合成也仍受真实上下文上限约束。
这不是浏览器、动态网页或任意联网工具。版本相关文档应由 Primary 批准正确版本入口。

### 预批准脚本操作

```json
{
  "capabilities": {
    "operations": {"json-summary": ["data/readings.json"]}
  }
}
```

当前只有固定 `json-summary`：对批准文件中的有限数值数组返回 count/sum/min/max
和真实输入hash；浮点求和不承诺任意大整数的精确算术。每任务最多4次，每次30秒。
它不是模型自写脚本执行器，不接受 shell、表达式、额外 argv 或安装命令。
宿主已有完整检查仍自动运行，不由这个工具替代。
固定程序在宿主权限下执行，不能将 `-I` 或路径allowlist宣传成OS沙箱。

### 单层只读子任务

```json
{
  "capabilities": {
    "children": {"read": ["src/parse.py", "tests/test_parse.py"]}
  }
}
```

Agent 可自主选择具体问题及批准文件的子集；最多2个孩子，串行使用同一个 iq3_s。
每个孩子最多4请求/8工具动作，真实消耗扣父任务总账，取消与总时间约束向下传播。
孩子没有写入、联网、执行或派孙任务权限。孩子的报告不是验收，父 Agent 须核对整合。

只读父任务总上限16请求/24工具/1200秒；实现父任务保持核心16请求/24工具/1800秒及
原编辑/完整检查预算。不能因子任务未成功就另外充值。只读研究摘要最多2000字符，
超限由模型在原预算内纠正，不由宿主截断成“成功”。

公开资料可与命名操作组合；只读子任务可用于实现中的依赖调查。
公开联网与子任务同时启用目前会被拒绝，未验证的组合不能悄悄开放。
本轮联网只取得**只读研究**资格，不要给可写实现任务授予 web；参数能被解析并不
等于组合已合格。公开网页与代码生成/执行的组合没有准入。

## 执行信任边界

实现检查会导入并执行修改后的 Python 源码，使用验证进程的实际宿主权限。
因此“没有 shell 工具”**不等于**生成的 Python 代码不能产生系统副作用；
编辑allowlist、命名操作和 `-I` 都不是操作系统沙箱。本预览继续假定可信本地仓库，
不适用于敌意仓库，也没有证明网页提示注入与自动代码执行的组合安全。
不要把不可信网页直接带入可写任务并自动执行；任意生成脚本需要另行审查或真正的
执行隔离，不能靠模型自己批准。只读公开研究与固定操作不执行模型生成代码。

## 入口

研究任务用现有 `.local-agents/strata-readonly.py prepare --request ... --config ... --apply`，
再 `run --task-id ... --attempt-id ...`。
实现任务用 `.local-agents/strata-worker.py prepare --task ... --config ... --apply`，
再使用其正常 run 入口。每次任务/尝试须有独立合法身份，不能重用已关闭试验目录。

安装从对应冻结候选的 `install.py --target <新隔离项目>` 开始；目标必须没有既有
`.local-agents`。不覆盖真实项目的已有安装或未提交改动。
实现路径继续走宿主编辑、格式化、完整检查、fresh Reviewer 和 Primary 最终验收；
可选工具取得的信息不等于验证通过。当前新功能不是全局默认，也不意味着生产全开。

这里的实现 `run` 本身返回 `ready_for_primary`，**不会自动完成独立 Reviewer 或接受**。
本轮完整链由隔离实验驱动器转交给冻结的 C1 Reviewer；该专用实验驱动器不在试用包中。
正式项目的 Primary 仍须安排独立审查请求与终验，不能把本包描述成已完成通用自动
Reviewer 调度的整套产品。只读研究任务则直接产生待 Primary 核对的报告。

## 已知边界

超时适配器的两次独立调查曾产生不受支持的运行时保证，保持 HOLD。
数据过滤恢复题只能证明其自身任务族，不证明任意语义审查、通用计划拆解或云成本节省。
匿名网页证据、孩子结论及模型关于来源版本的解释仍需核对；机器输入hash和实际检查
比模型关于hash的措辞更可靠。
需要任务明确请求了独立上下文，对照也明确给出完整本地答案；这些成绩不证明
模糊真实任务下的最佳工具选择或派工收益。数据表的核心结论已核验，报告附带的
泛化措辞并未全部认证（例如笼统描述对象identity），不能把研究笔记当权威规则。
