# Strata 可选能力实验与稳定范围

2026-10-24。按最新用户指令自主推进，weekly used上限50%（起点实测25%）。
这是已完成核心阶段之后的新授权范围，不改写旧S5/S6未准入记录或已有失败。
目标是在稳定C3之外，逐项得到有证据的可试用能力，保留不合格项为默认关闭。

核心C3为0.2.0-observed-version.3，发布ZIP SHA256

## 固定推进顺序

1. **能力清单和离线扩展接口**：冻结DEV起点/preimages，检查安装实际接口；新增
   显式只读入口，复用read/search/native loop。拒绝所有写入/执行工具，无假修改路径。
   报告只校验证据来源、字段和当前版本，语义正确性仍由Primary判断。核心115控制
   和新增只读负控通过后才live；旧C3产品不变。
2. **只读调查4格**：找调用方、缺失证据、有限范围负面搜索、相互冲突的信息，4/4
   结论真实且有边界、0编造引用/执行。每格≤8HTTP、12取证、16工具、900秒、0编辑。
3. **fresh审查12格**：6真实缺陷+6正确改动，全部有实际检查及原始diff，含检查全绿
   的边界错误和看似危险但合法的实现。每格≤10HTTP、12取证、16工具、900秒、0编辑。
   原门槛：严重缺陷0漏报、全部缺陷≥5/6、正确误拒≤1/6、0伪造执行/引用。
   不合格则审查保持关闭，核心仍由Primary完整终验；不反复抽同一证据求PASS。
4. **Skills说明文档实验**：只挂载审批且hash固定的摘要，按需加载正文，使用已安装
   registry/provider接口；不扫描用户目录，不执行skill脚本。离线拒绝漂移/未知skill/
   权限注入后，冻结2种问题×有无skill=4格，同角色预算。比较遗漏、阻塞和Primary
   介入，不为“全用上”保留无收益复杂度。
5. **受控文档获取**：先核对实际Web provider，优先官方文档精确URL/文档ID，最多
   2格只读live。拒绝非批准域、重定向/私网/任意query/源码出站；网页视为不可信证据。
   没有可用provider则明确NOT_AVAILABLE，不展示假搜索能力。外网抓取不授予shell。
6. **规划能力决策**：利用上述成本记录判断Coordinator是否值得。可先做无执行权限的
   计划→任务包机械可行性核对；只有有实际拆分成本证据才另注册planning实验。此处
   不启用递归Agent、并发写入、多模型或模型自行派工。它们是不同信任边界，不随
   “希望功能都试验”自动开放。

上述固定首轮最多22个live单元，不要求用满。各能力独立判定、单模型串行。
各批冻结前登记具体材料、来源、暴露状态、顺序、预算、oracle和普通失败继续规则。
项目已有完整检查复用同版本证据；外部pytest必须显式-c项目配置，消息fixture使用
稳定身份或复用原对象。新oracle先做正负控，避免把测试编排问题算成模型能力。

## 失败后怎么推进

普通字段/引用错误：同一格原预算内返回准确字段/引用事实；不得改提示或充值。
确定性接口/安全故障：停止该能力live，原失败封存，离线复现后窄修；新候选重验
受影响控制，原题永久暴露。最多一个有明确假设的后续诊断批，不无限重命名重跑。
语义漏检或无新证据循环：结算原格并完成安全独立格；批末判HOLD及能力边界。
只读角色不通过不阻断彼此无依赖的Skills/Web离线准备，也不撤销核心已有资格。
同一签名跨两个候选无改善、三个同单元无进展、修A坏B或weekly增加5点无推进时
先写一页证据复盘；只有新可证伪机制才继续，不靠更多相同抽样。

达到50%停止新派工，安全收尾；无法观测用量或模型/文件漂移则先核查。重大执行/
信任边界变化、外部凭据/安装需求才找用户，其余按此计划自主推进。

## 交付

每项registration、离线控制、逐格request/response/actions/report、Primary disposition、
metrics/decision/handoff。阶段汇总列：稳定已用、实验可试、未通过、不可用、未测试。
Primary仍负责合同/权限与最终接受；fresh review首次通过不减其义务。云成本/主动
时间没有可靠测量写unknown，weekly不换算节省。可选能力保持显式开启，不能因离线
控制通过就宣布production enabled。最终交付可试用组合和明确边界，不自动发布。
