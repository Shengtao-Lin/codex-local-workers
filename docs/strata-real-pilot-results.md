## 条件复测：已有严格报告配置

记录：`benchmarks/work/harness-convergence/strata-real-report-profile-20261025-1/`。
仅对前两道已暴露任务使用冻结代码已有的只读报告配置，任务/材料/2000字符合同不变。
启用 `experimental_strata_capabilities: true`，但任务 capabilities 为空，未授予额外权限。
组合差异为宿主2000字符门槛、报告 schema 和10请求上限（原8）；不能归因于单一因素。

离线负控验证超长报告被拒绝，空授权下写入、联网、固定操作、子派工均被拒绝，

其中“没有事务包裹 MLflow 调用”只能理解为没有证明跨系统原子性，不能据此宣称
外层没有 SQL 事务；Worker 明确未读外层提交循环，Primary 已记录这一复用边界。

条件复测最终 **1/2接受，HOLD_REPORT_PROFILE**。文档整理三次 report 摘要为
2908、2662、2075字符，均超过2000，耗尽2次协议恢复机会后停止；没有最终合法报告。

因此不是总时间或模型请求耗尽，更不是 Reviewer 拒绝。未人工压缩、续跑或替换成绩。
草稿仍包含旧迁移期间行状态处理背景，不能据此增加本次升级要求。

两项复测共14请求、929秒。源码调查实际仍为8请求，277.39秒，高于原206.765秒，
不能声称提速。复测只说明已有严格门槛能拦截交付违规；并未稳定解决报告收敛。
不把复测替代原失败，也不将两批拼成“新题3/3”。

## 边界与成本

本轮无 runtime、模型、生产默认配置或审查方法变更，无 commit/push。
所有旧失败和初次零模型夹具准备失败均保留；后者是 Primary 夹具类型检查失败，
不是模型失败。离线脚本/夹具开发成本与任务执行中的合同、定位和审查成本分开看待。

统一入口让 Strata 自主读取、实现、自测和修复，宿主驱动检查与 fresh Reviewer；
Primary 仍负责合同、权限、关键测试和最终接受。没有自动 Reviewer→Coder 无限回路。
可信项目 Python 检查使用宿主权限，不是 OS 沙箱。未放行任意 shell、通用递归、
Coordinator 或网页与可写实现混用。熟悉兄弟项目的这几道任务不能证明未知任务通用稳定。

结论：保留已有受监督预览资格，不扩大生产资格。此次真实局部实现证明了无需
逐步语义指导的自测修复与完整审查路径可以工作；只读跨文件调查有可核对成果，
但复杂文档的压缩交付仍不可靠，宿主拦截不等于任务完成。停止于固定批次结论，
不是预算耗尽：最终观测 weekly used 35%，本轮上限50%。不再围绕本题追加抽样。
