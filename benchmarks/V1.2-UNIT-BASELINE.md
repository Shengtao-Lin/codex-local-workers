The runner emitted 17 `repair_focus_issued` events, followed immediately by
an edit in 9 cases/events (**9/17, 52.9%**). Eleven units had at least one
repair focus; eight of those reached `ready_for_review` (**8/11**). These are
first-packet outcomes, not inherited-rework conversion rates. The high-risk
`reviewer-citation` fixture required source citation twice and converged once
(**1/2**). Independent pytest and Ruff passed in each of the nine Coder-ready
units, including those whose Reviewer later failed.

Maximum *reported* context utilization was 31.91% Explorer, 52.35% Coder,
and 47.98% Reviewer. The archived requests record 77 / 128 / 75 model calls
for Explorer / Coder / Reviewer respectively, with 230,469 / 528,385 /
355,664 reported cumulative **input** tokens. Output tokens are not available
from these archives and must not be inferred from `max_output_tokens`.
Average Coder calls per unit were 10.7; Reviewer calls averaged 8.7 among
the nine reached units. Summed unit wall time was 1,141.5 seconds; this
excludes any offline Primary analysis after the run.

## Decision and next focused work

**NO-GO for v1.2 exit / live v2.1 Coordinator routing.** Compatibility and
infrastructure handling passed, but 41.7% E2E and 66.7% conditional Reviewer
validity are not stable enough. `metadata-limit` repeated the exact Reviewer
read-loop failure in both rounds; `internal-trace` repeated the same Coder
repair no-progress failure in both rounds. `reviewer-citation` passed its
high-risk source-ref path only in round 1. `sample-identity` alternated an
Explorer no-evidence failure and a Coder repair failure. Context utilization
does not explain these failures.

Next, diagnose the two reproducible read/repair loops from their frozen
traces. Make only targeted protocol or packet fixes, retain this batch as the
pre-fix baseline, and rerun the same frozen cases in a new batch. Do not
silently reclassify Reviewer `not_run` as a model failure or merge before/after
data. Public benchmark cases remain a second layer after local convergence.
